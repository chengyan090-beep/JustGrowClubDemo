## Demo 内容

- 用户端：企微触达、需求问答、画像生成、推荐主页、活动详情、需求广场
- 资源侧：主理人工作台、主理人发起成熟活动、商户工作台、商户资源录入、角色化响应需求广场、收益复盘
- 运营端：需求总览、AI 需求树、资源匹配、AI 提案生成、预活动共创、正式触达
- 独立全体图：放在小程序演示下方，整合系统总览和方案聚焦，说明项目如何聚焦人群/需求、连接企微与小程序、组织角色共创，并实现社区运营目标

## 最新版本说明

当前版本将“系统总览图”和“方案聚焦图”从小程序流程中独立拆出，不再作为运营端步骤出现。小程序演示专注展示用户端、资源侧和运营端的真实流程；页面最下方新增一张独立全体图，用于路演收束：说明项目聚焦什么人群与需求、如何通过企微 + 小程序 + AI 第二大脑连接主理人/商户/运营方，最终实现空间活化、商户导流、社群沉淀和运营提效。
