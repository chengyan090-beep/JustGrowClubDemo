# JustGrowClubDemo

创智天地 AI 社区第二大脑 Demo。

## 在线访问

https://chengyan090-beep.github.io/JustGrowClubDemo/

如果在微信中打开出现“将要访问非微信官方网页”，点击“继续访问”即可。建议使用手机浏览器或电脑浏览器查看完整效果。

## Demo 内容

- 用户端：企微触达、需求问答、画像生成、推荐主页、活动详情、需求广场
- 资源侧：主理人入口、商户入口、运营方入口、主理人活动列表、成熟活动自助发布、角色化响应需求卡
- 运营端：需求总览、AI 需求树、资源匹配、AI 提案生成、预活动共创、正式触达
- 独立全体图：放在小程序演示下方，整合系统总览和方案聚焦，说明项目如何聚焦人群/需求、连接企微与小程序、组织角色共创，并实现社区运营目标

## 最新版本说明

当前版本将用户端首页重心调整为“需求镜像 + 2-3 个推荐活动 + 其他活动一览”，强化用户一进来就产生“它懂我”的感受。资源侧补齐主理人、商户、运营方入口，并把“需求卡 → AI 预活动 → 资源响应 → 对接群 → 承接发布”整理成父子层级。成熟活动由主理人或商户自助发布；运营方重点审核 AI 提案是否适合转正，减少额外审核负担。
